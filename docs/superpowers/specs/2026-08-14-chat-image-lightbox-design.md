# 对话图片紧凑预览与灯箱设计

## 目标

对话中的图片以紧凑、自适应原比例的卡片展示，点击图片后在应用内灯箱查看完整内容，并支持另存为和定位会话工作区中的原文件。

## 交互

- 单图最大约 `420×320px`，窄屏下不超过消息内容宽度；图片使用 `object-contain`，不裁剪。
- 多图使用紧凑网格，单元格保持 `contain`，整体宽度不超过单图上限。
- 灯箱使用现有 Base UI Dialog：最大图片区域为视口的 `90vw × 85vh`，支持 Esc、遮罩点击关闭、左右按钮和方向键切换。
- 灯箱操作栏提供另存为、可用时的定位原文件，以及关闭按钮。另存为取消不产生错误提示。
- `workspace://` 图片显示定位原文件；data URL、Blob URL 或外部 URL 只显示另存为。

## 数据流与接口

- `MessageAttachments` 从当前媒体状态生成图片条目，并保留原始工作区相对路径。
- 新增 `ImageLightbox` 组件管理当前索引、键盘事件、保存状态和错误状态。
- 主进程新增 `workspace:saveMediaAs`，接收图片二进制、文件名和媒体类型，弹出系统保存对话框并写入目标文件。
- 主进程新增 `workspace:revealFile`，校验会话工作区相对路径后调用 `shell.showItemInFolder`。
- IPC、preload、renderer API 和中英文 i18n 同步更新。

## 失败处理

- 图片加载失败沿用现有媒体错误占位。
- 保存失败或定位失败显示本地化 toast，灯箱保持打开以便重试。
- 路径越界、文件缺失和无工作区路径不会被静默放行。

## 验证

- 覆盖单图/多图布局、原比例、灯箱索引、键盘关闭与切换、保存和定位按钮条件。
- 主进程覆盖保存取消、保存成功、路径越界和文件缺失。
- 运行 `vp check`、`vp run ayaka-desktop#test` 和 `vp run ayaka-desktop#typecheck`。
