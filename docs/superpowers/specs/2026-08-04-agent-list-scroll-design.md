# 智能体列表滚动布局设计

## 目标

当智能体卡片数量超过可视区域时，顶部统计卡片和列表工具栏保持固定，只让卡片列表区域纵向滚动。卡片之间应保持独立布局，不因列表高度不足而重叠或被后续行覆盖。

## 方案

在 `AgentsPanel` 中将卡片区域拆成两层：

- 外层作为唯一滚动容器，使用 `min-h-0 min-w-0 flex-1 overflow-y-auto`，由父级 flex 布局提供可用高度。
- 内层使用 grid 承担两列布局和卡片行间距，并使用自然行高，不再让滚动容器同时承担 grid 项目的尺寸计算。
- `AgentCard` 使用自然高度和 `min-w-0`，保留卡片内部的 flex 结构与操作行为，避免依赖不确定的 `h-full` 高度。

不修改智能体数据筛选、排序、业务操作、IPC 或持久化逻辑。

## 验收标准

1. 统计卡片、标签页、搜索框、刷新和新建按钮在列表滚动时保持可见。
2. 智能体卡片超过可视区域后，鼠标滚轮可以在卡片区域纵向滚动，并能访问全部卡片。
3. 卡片内容、底部操作栏和相邻网格行不发生重叠。
4. 空列表状态和现有卡片操作行为保持不变。

## 验证

运行桌面应用相关的格式、lint、类型检查；若仓库检查命令可用，再运行 `vp check`。本次没有新增数据逻辑，因此不新增持久化或 IPC 测试。
